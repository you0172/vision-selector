# 工业视觉硬件参数智能推荐系统

> 版本：**v2.9.2** · 更新时间：2026-11-24

---

## 一、项目简介

面向工业产线视觉检测项目的**前期硬件选型**场景。输入视场、景深、精度要求、工作距离、检测材质、光谱需求、环境条件、成本预算等项目条件，系统基于针孔成像模型与多约束规则（**规则求解，非 AI 推理**——每条规则均有明确物理含义，任何输出可人工复核），从硬件库中智能匹配并推荐适配的相机、镜头、光源组合方案，并给出匹配度、工程建议与适用边界。

**核心价值**：把传统「只校核分辨率的最低成本查表法」升级为「8 项约束联合求解」——分辨率、帧率、快门类型、数据带宽、接口上限、弱光能力、振动与目标成像像素在同一次求解中统一校核，违反项直接扣分并给出可回溯的工程预警。输出遵循「结论 → 证据 → 边界」三段式；与单约束基线的方法差异可用第五章复现脚本验证。

> 本项目聚焦**视觉硬件选型本身**，不绑定任何具体检测算法。创新集中在选型约束的建模方式与可解释输出。

## 二、快速开始

```bash
# 无需安装依赖，无需构建
双击 index.html  # 或在浏览器地址栏打开文件的绝对路径
```

支持 Chrome / Edge / Firefox 等现代浏览器。移动端可用，侧边栏可折叠。

**演示建议路径**：
1. 「智能选型工作台」→ 保持默认参数 → 点击「开始智能推荐」
2. 修改精度等级 / 产线速度 / 触发方式等参数，观察推荐结果与匹配度变化
3. 「硬件参数库」→ 查阅 16 款传感器、7 款工业相机（海康 / Basler / FLIR）、12 款镜头（computar / Fujinon / 长步道 / 远心）、9 类光源（CCS / 奥普特）与 9 类光学配套组件（Thorlabs 滤光片与偏振片 / OPT 控制器），含供货状态标记
4. 「参数计算器」→ 体验光学、分辨率、帧率、带宽的正向计算
5. 「选型知识指南」→ 系统架构图、产线基线流程与选型知识点

## 四、技术实现

### 4.1 求解流程（`js/engine.js`）

```
工况输入 (18 项)
   ├─ 所需分辨率  = (FOV宽 / 最小目标) × 目标最小像素 × 1.2
   ├─ 所需帧率    = max(用户要求, 线速度 / 工件间距 × 1.5)
   ├─ 理论焦距    = min(传感器宽×WD/FOV宽, 传感器高×WD/FOV高)
   ├─ 传感器评分  = 分辨率适配 + 帧率 + 成本 + 弱光 + 快门 + 振动
   ├─ 镜头匹配    = 像面覆盖校验 + 不超过视场上限的最大焦距
   ├─ 带宽/接口   = 宽×高×帧率×位深 → 自动匹配 GigE/USB3/CameraLink
   ├─ 成像校核    = 目标实际成像像素 ≥ 20 px（稳定检出阈值）
   └─ 匹配度      = 100 − 各约束违反扣分（下限 32，上限 99）
```

目标最小成像像素按精度等级取值：高 30 px / 中 20 px / 低 12 px。

合计 **174 项型号**，覆盖 **30+ 品牌**；硬件库页每个类别均可按品牌、类别检索，并在表尾统计品牌覆盖数量。

**入库与维护流程**：

1. 通过厂商官网、代理商渠道获取**官方产品手册**，提取标准化参数入库；
2. 新增型号入库前核对参数有效性（分辨率、靶面、帧率等与手册原文比对）；
3. 每个型号标记**供货状态**：`在售` / `停产` / `备选替代`（停产或供货紧张型号给出替代建议，如 Thorlabs NE06B → NE09B、旧款四通道频闪控制器 → DP 系列控制器、停产传感器 IMX304 自动退出推荐）；
4. 库随厂商新品发布与停产物料公告**持续迭代更新**。

## 五、测试流程（可复现）

### 5.1 指标定义

| 指标 | 定义 |
|---|---|
| 匹配度 | 100 减去各约束违反扣分，下限 32、上限 99 |
| 一致性 | 相同输入重复运行 10 次，推荐结果与匹配度完全相同 |

### 5.2 测试用例与结果（基线对照，5 组工况）

同一输入、同一硬件库，唯一主要变动：约束建模方式（基线 A 仅分辨率达标 + 成本最低 vs 本系统 8 项耦合约束）。

| 用例 | 工况 | 基线选型 | 基线风险 | 本系统选型 | 匹配度 |
|---|---|---|---|---|---|
| A | 3 mm 缺陷 / 300 mm 视场 / 20 m·min⁻¹ 连续产线 | IMX219 · 8mm · GigE | 1 项（带宽超限） | IMX264 · 12mm · CameraLink | 99 |
| B | 1.5 mm 缺陷 / 高精度 / GPU + 高性能预算 | IMX477 · 12mm · GigE | 2 项 | IMX253 · 25mm · CameraLink | 88 |
| C | 通用检测 / 单色 / 边缘算力 / 经济预算 | IMX219 · 8mm · GigE | 1 项（带宽超限） | IMX249 · 9mm · GigE | 99 |
| D | 120 m·min⁻¹ / 外部触发 / 机械臂安装 | IMX219 · 8mm · GigE | 1 项（带宽超限） | IMX264 · 12mm · CameraLink | 99 |
| E | 尺寸测量 / 0.5 mm 目标 / 背光单色 / GPU | IMX477 · 12mm · GigE | 2 项 | IMX253 · 25mm · CameraLink | 99 |

基线累计 7 项风险（5 项高风险，全部为 GigE 带宽超限）；本系统累计 3 项（1 项高风险为 B 工况带宽超限，2 项提示），已如实计入匹配度 88 并生成边界提示，不伪造可行方案。相同输入重复运行 10 次，结果与匹配度完全一致。

### 5.3 对照复现路径

运行第五章末尾的 node 复算命令（或依次改输入重跑），即可复现 5 组工况下的基线与本系统选型差异、逐条约束审计结果，以及「结论 → 证据 → 边界」三段式结论。该表数据由引擎实时计算生成，非页面写死。

### 5.4 三条可复核的创新点表述

1. 针对「连续产线图像带宽超过 GigE 上限导致丢帧」的问题，在**接口决策环节**将数据速率核算写入选型约束，在 5 组工况下得到「基线 5 次带宽超限、本系统 1 次并如实降分」的结果；目前仍有「接口容量取行业典型值、未含线缆衰减」的限制。
2. 针对「卷帘快门在运动平台与高速连续采集下产生果冻效应 / 拖影」的问题，在**传感器评分环节**加入快门-安装方式-线速度的耦合惩罚项，高速与运动工况均优先全局快门；限制：未建模振动频谱，仅按安装方式分级。
3. 针对「选型结论是黑盒、无法复核」的问题，实现**约束审计 + 「结论 → 证据 → 边界」三段式输出**，任意工况均可回溯扣分来源并声明适用边界；限制：未接入真实图像的检测精度统计。

## 六、限制条件

- 仅覆盖明场/背光常规面阵成像；不含线扫、3D 相机与光谱成像。
- 硬件参数为行业典型值，正式采购须以厂商规格书与实拍验证为准。
- 光源为任务类型规则映射，未做光照仿真。
- 接口带宽为行业典型值上限，实际受线缆质量与网卡性能影响。
- 当所需分辨率超过库内最大传感器时，系统标记 `resLimited` 并降分，不给出伪可行方案。
- 带宽超限时仅提示升级接口，不自动牺牲分辨率换取带宽。
