## 一、项目简介

面向工业产线视觉检测项目的**前期硬件选型**场景。输入检测目标尺寸、视场、工作距离、产线节拍、光照与预算等工况参数，系统基于针孔成像模型与多约束评分，输出相机传感器、镜头、光源、接口及 YOLOv26 模型变体的一体化配置建议，并给出匹配度、工程建议与失败边界。

**核心价值**：把传统「只校核分辨率的最低成本查表法」升级为「8 项约束联合求解」，在 5 组对照工况中把部署返工风险从 5/5 降到 0/5。

> ⚠️ 本项目**不以"使用了 YOLO / AI"作为创新点**。创新集中在选型约束的建模方式与可解释输出，详见 `js/data.js` 的 `innovations` 字段。

## 四、技术实现

### 4.1 求解流程（`js/engine.js`）

```
工况输入 (18 项)
   ├─ 所需分辨率  = (FOV宽 / 最小目标) × 目标最小像素 × 1.2
   ├─ 所需帧率    = max(用户要求, 线速度 / 工件间距 × 1.5)
   ├─ 理论焦距    = min(传感器宽×WD/FOV宽, 传感器高×WD/FOV高)
   ├─ 传感器评分  = 分辨率适配 + 帧率 + 成本 + 弱光 + 快门 + 振动
   ├─ 镜头匹配    = 像面覆盖校验 + 不超过视场上限的最大焦距
   ├─ 带宽/接口   = 宽×高×帧率×位深 → 自动匹配 GigE/USB3/CameraLink
   ├─ YOLO 变体   = 目标成像像素 + 算力 + 节拍 + 预算 → n/s/m/l/x
   └─ 匹配度      = 100 − 各约束违反扣分（下限 32，上限 99）
```

目标最小成像像素按精度等级取值：高 30 px / 中 20 px / 低 12 px。

### 4.2 对照基线

`Engine.baselineSelect()` 模拟工程常见的单约束查表法：**仅按分辨率达标取最低成本传感器**，按经验指定 GigE 接口，不校核帧率、快门、带宽与目标像素。对照实验与实验组使用同一份输入和同一份硬件数据库，差异仅在算法本身。

### 4.3 依赖

零第三方依赖，无网络请求，全部计算在本地浏览器完成。

## 五、测试流程（可复现）

### 5.1 指标定义

| 指标 | 定义 |
|---|---|
| 部署风险数 | 违反带宽上限 + 运动场景卷帘快门 + 目标成像像素 < 20 px 的项数之和 |
| 匹配度 | 100 减去各约束违反扣分，下限 32、上限 99 |
| 一致性 | 相同输入重复运行 10 次，推荐结果与匹配度完全相同 |

### 5.2 测试用例

| 用例 | 工况 |
|---|---|
| A | 3 mm 缺陷 / 300 mm 视场 / 20 m·min⁻¹ 连续产线 |
| B | 1.5 mm 缺陷 / 高精度 / GPU + 高性能预算 |
| C | 通用检测 / 单色 / 边缘算力 / 经济预算 |
| D | 120 m·min⁻¹ / 外部触发 / 机械臂安装 |
| E | 尺寸测量 / 背光单色 / 高精度 / GPU |

### 5.3 结果

| 用例 | 基线风险数 | 基线选型 | 本系统选型 | 匹配度 | 一致性 |
|---|---|---|---|---|---|
| A | 2 | IMX219 · 8mm | IMX264 · 12mm · CameraLink | 99 | 10/10 |
| B | 2 | IMX477 · 12mm | IMX253 · 25mm · CameraLink | 88 | 10/10 |
| C | 2 | IMX219 · 8mm | IMX219 · 8mm · USB3 | 99 | 10/10 |
| D | 1 | IMX219 · 8mm | IMX264 · 12mm · CameraLink | 99 | 10/10 |
| E | 2 | IMX477 · 12mm | IMX253 · 25mm · USB3 | 99 | 10/10 |

**合计**：基线累计 9 项部署风险，本系统 0 项；匹配度区间 88–99。

> 在应用内「实验与验证」页可现场重算上述结果；「创新点论证」页提供实时基线对照表。

## 六、创新点与迭代证据

### 6.1 三个创新点

1. **多约束耦合求解替代单约束人工查表** — 6 类约束写入同一评分函数并对违反项直接预警；证据：5/5 → 0/5。
2. **成像参数与检测模型联合决策** — 目标成像像素反向约束分辨率，并联动 YOLO 变体与输入尺寸。
3. **可解释匹配度与失败边界显式输出** — 逐条回溯扣分来源，不满足时主动降分而非伪造方案。

### 6.2 迭代记录

| 版本 | 改动 | 工况 A 结果 |
|---|---|---|
| v1.0 | 仅分辨率 + 最低成本 | IMX219 卷帘快门，风险 2 项 |
| v2.0 | 加入运动场景快门惩罚 | 改选 IMX264 全局快门，风险 1 项 |
| v2.6 | 带宽/接口/弱光/振动/模型算力联合评分 | CameraLink + 边缘部署建议，风险 0 项，匹配度 99 |

## 七、限制条件

- 仅覆盖明场/背光常规面阵成像；不含线扫、3D 相机与光谱成像。
- 硬件参数为行业典型值，正式采购须以厂商规格书与实拍验证为准。
- 光源为任务类型规则映射，未做光照仿真。
- 模型 mAP 与 FPS 为公开典型值，未接入真实图像实测。
- 当所需分辨率超过库内最大传感器时，系统标记 `resLimited` 并降分，不给出伪可行方案。
- 带宽超限时仅提示升级接口，不自动牺牲分辨率换取带宽。
